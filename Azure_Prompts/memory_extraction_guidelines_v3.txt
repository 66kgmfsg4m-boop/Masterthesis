?????? CRITICAL: EXTRACT PART NUMBER FIRST! ??????

**BEFORE EXTRACTING ANY PROPERTIES:**
1. Find the Part Number on page 1 (e.g., "FM18W08")
2. Decode it using the tables below
3. ONLY THEN extract other properties

?? NEVER return "nicht vorhanden" for Function - ALWAYS decode from Part Number!
?? NEVER return text like "256 Kbit" for SizeByte - ALWAYS convert to bytes!

Memory components are SERIES DATASHEETS where specifications vary by
model number. You MUST decode the Part Number to get exact specs!

???????????????????????????????????????????????????????????????????
?? STEP 1: EXTRACT PART NUMBER
???????????????????????????????????????????????????????????????????

MANDATORY: Extract manufacturer Part Number from title page!

EXAMPLES:
  • "FM18W08" (Cypress F-RAM)
  • "AT28C256" (Atmel EEPROM)
  • "M95256" (STMicro Serial EEPROM)

This Part Number encodes ALL specifications!

???????????????????????????????????????????????????????????????????
?? STEP 2: DECODE PART NUMBER TO GET FUNCTION
???????????????????????????????????????????????????????????????????

DECODING TABLE - Memory Type from Prefix:
????????????????????????????????????????????????
? Prefix     ? Memory Type  ? Function         ?
????????????????????????????????????????????????
? FM         ? F-RAM        ? "FRAM"           ?
? AT28       ? Parallel EEPROM? "EEPROM"       ?
? AT25       ? Serial EEPROM? "EEPROM"         ?
? M95        ? Serial EEPROM? "EEPROM"         ?
? MX25       ? Serial Flash ? "NOR Flash"      ?
? IS62WV     ? SRAM         ? "SRAM"           ?
? CY62       ? SRAM         ? "SRAM"           ?
????????????????????????????????????????????????

EXAMPLE: FM18W08
  Prefix: FM ? Function = "FRAM"

EXAMPLE: AT28C256
  Prefix: AT28 ? Function = "EEPROM"

WRONG: Function = "nicht vorhanden" or "Memory"
CORRECT: Decode from Part Number!

???????????????????????????????????????????????????????????????????
?? STEP 3: DECODE CAPACITY AND CALCULATE SizeByte
???????????????????????????????????????????????????????????????????

Part Numbers encode capacity as suffix number!

DECODING TABLE - Capacity from Suffix:
????????????????????????????????????????????????
? Part Number? Capacity     ? SizeByte (bytes) ?
????????????????????????????????????????????????
? FM18W08    ? 256 Kbit     ? 32768            ?
? FM18W16    ? 512 Kbit     ? 65536            ?
? AT28C64    ? 64 Kbit      ? 8192             ?
? AT28C256   ? 256 Kbit     ? 32768            ?
? M95256     ? 256 Kbit     ? 32768            ?
? M95M01     ? 1 Mbit       ? 131072           ?
????????????????????????????????????????????????

CONVERSION FORMULA:
  Kbit * 1024 / 8 = Bytes

EXAMPLE: FM18W08
  Suffix: 08 ? 256 Kbit
  Calculation: 256 * 1024 / 8 = 32768
  SizeByte = "32768"

WRONG: SizeByte = "256 Kbit (32 K × 8)"
CORRECT: SizeByte = "32768"

???????????????????????????????????????????????????????????????????
?? STEP 4: DECODE ORGANIZATION AND GET WidthMax
???????????????????????????????????????????????????????????????????

Find Organization in datasheet (usually on page 1)

EXAMPLES:
  "32K × 8"  ? WidthMax = "8 bit"
  "64K × 1"  ? WidthMax = "1 bit" (Serial)
  "16K × 16" ? WidthMax = "16 bit"

WRONG: WidthMax = "3.9 mm" (that's package width!)
CORRECT: WidthMax = "8 bit" (data bus width)

???????????????????????????????????????????????????????????????????
?? STEP 5: READ TaaMaxS FROM TIMING TABLE
???????????????????????????????????????????????????????????????????

IF Parallel Memory:
  Read tAA(Max) from AC Characteristics table
  Example: "70 ns"

IF Serial Memory:
  TaaMaxS = "nicht relevant" (no address access time)

?? COMMON MISTAKES TO AVOID
???????????????????????????????????????????????????????????????????

? MISTAKE #1: Not decoding Part Number
   WRONG: Function = "nicht vorhanden"
   RIGHT: Decode FM18W08 ? Function = "FRAM"

? MISTAKE #2: Not converting SizeByte to bytes
   WRONG: SizeByte = "256 Kbit (32 K × 8)"
   RIGHT: SizeByte = "32768"

? MISTAKE #3: Using package dimensions for WidthMax
   WRONG: WidthMax = "3.9 mm"
   RIGHT: WidthMax = "8 bit" (from organization)

???????????????????????????????????????????????????????????????????
?? PART NUMBER DECODING REFERENCE
???????????????????????????????????????????????????????????????????

CYPRESS F-RAM (FMxxWxx):
  FM = Ferroelectric Memory (F-RAM)
  18 = 1.8V to 3.6V supply range
  W = Wide Voltage
  08 = 256 Kbit (32K × 8)
  16 = 512 Kbit (64K × 8)

ATMEL EEPROM (AT28Cxxx):
  AT = Atmel
  28 = Parallel EEPROM
  C = CMOS
  64 = 64 Kbit (8K × 8)
  256 = 256 Kbit (32K × 8)

STMICRO SERIAL EEPROM (M95xxx):
  M95 = Serial EEPROM (SPI)
  256 = 256 Kbit
  M01 = 1 Mbit

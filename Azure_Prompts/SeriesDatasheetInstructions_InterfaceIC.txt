?? **WHAT IS A PART NUMBER CHART?**
A table or figure showing how different part number segments encode product features:
- **Funktion** (Interface type: Controller, Driver, Transceiver, etc.)
- **Interface_internal** (Internal interface: UART, SPI, I2C, USB, etc.)
- **Interface_external** (External interface: RS-232, RS-485, CAN, Ethernet, etc.)
- **Number of Pins** (Package pin count)
- **PackageType** (SOIC, QFN, TSSOP, etc.)

**TYPICAL SEGMENTS IN INTERFACE IC PART NUMBERS:**

1?? **BASE MODEL** (Family Name)
   • Example: `MAX3232`, `SP3232`, `ADM3251E`, `ISO1050`
   • Indicates interface type: RS-232, RS-485, CAN, I2C, etc.

2?? **INTERFACE TYPE/FUNCTION** (Character or Digit)
   • Example: 
     - `E` = RS-232 Transceiver
     - `D` = RS-485 Driver
     - `R` = RS-485 Receiver
     - `C` = CAN Controller
     - `T` = USB-to-UART Bridge
   • CRITICAL: This determines "Funktion" property!

3?? **INTERNAL/EXTERNAL INTERFACE** (Implicit or Explicit)
   • Internal: UART, SPI, I2C, USB
   • External: RS-232, RS-485, CAN, Ethernet
   • Example: 
     - MAX3232 = UART (internal) ? RS-232 (external)
     - MCP2515 = SPI (internal) ? CAN (external)

4?? **NUMBER OF CHANNELS** (Digit)
   • Example: `2` = 2 channels, `4` = 4 channels, `8` = 8 channels

5?? **VOLTAGE/SPEED INDICATOR** (Character)
   • Example: 
     - `3` = 3.3V supply
     - `5` = 5V supply
     - `H` = High-speed
     - `L` = Low-power

6?? **PACKAGE TYPE** (Letters)
   • Example:
     - `E` = SOIC-16
     - `P` = PDIP-16
     - `UE` = TSSOP-16
     - `QFN` = QFN-24

7?? **TEMPERATURE RANGE** (Character)
   • Example: 
     - `C` = Commercial (0°C to +70°C)
     - `I` = Industrial (-40°C to +85°C)
     - `A` = Automotive (-40°C to +125°C)

8?? **TAPE & REEL SUFFIX** (Optional)
   • Example: `+T`, `-TR`, `/R`

?? CRITICAL RULES
???????????????????????????????????????????????????????????????????????????????

1?? **ChartFound = false** if:
   • No Part Number Chart exists in datasheet
   • Chart is too unclear to extract structure
   • Only single model number (no variants)

2?? **Capture ALL Segments**:
   • Even if some segments seem irrelevant
   • Include temperature range, tape/reel suffix
   • Keep original segment order from chart

3?? **PossibleValues MUST BE COMPLETE**:
   • Extract ALL options from chart
   • Include EXACT codes/letters
   • Map to "Funktion" dropdown options where applicable

4?? **Funktion Mapping** (CRITICAL for Interface ICs!):
   Map interface type to these EXACT values:
   • "Interface Controller"
   • "Interface Controller" (if manages the protocol)
   • "Driver , Receiver , Transceiver"
   • "Switch , Mux , Demultiplexer"
   • "Signal Buffer , Repeater , Splitter"
   • "Serializer , Deserializer"
   • "Coder , Decoder ( CODEC )"
   • "I/O Expander"
   • "Bridge"

5?? **Interface Detection**:
   • Internal interface: What the IC talks to on the host side (MCU/CPU)
   • External interface: What the IC talks to on the bus side (physical layer)
   • Example: 
     - UART-to-RS232 transceiver: Internal=UART, External=RS-232
     - SPI-to-CAN controller: Internal=SPI, External=CAN

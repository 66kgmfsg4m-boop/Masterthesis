# Series Datasheet Instructions - Non-Volatile Memory (Parallel + Serial + eMMC/UFS)

================================================================
 STAGE 1 of 2: PART NUMBER CHART EXTRACTION
================================================================

This datasheet covers a memory family with MULTIPLE variants
(different density, package, voltage, interface, ...). The
specifications vary based on the **PART NUMBER**.

This file is used for BOTH:
  * "Non-Volatile Memory Parallel" (Parallel NOR/NAND, parallel EEPROM, ...)
  * "Non-Volatile Memory Serial"   (SPI/QSPI Serial NOR, Serial EEPROM,
                                    Serial F-RAM/MRAM, eMMC, UFS, ...)

Your job in STAGE 1 is to extract the PART NUMBER STRUCTURE only.
DO NOT extract concrete property values yet (Size, Width, tAA, Pitch, ...).
Those come in STAGE 2 once a specific part number is known.

================================================================
 WHAT TO LOOK FOR
================================================================

A "Part Number Chart" / "Ordering Information" / "Part Numbering"
section that breaks down the part number into segments and lists
the meaning + possible values of each segment.

Typical locations:
  * First 1-3 pages (cover / overview)         -> SPI Flash, EEPROM, FRAM, MRAM
  * Last 5-10 pages (ordering info appendix)   -> Parallel NOR/NAND
  * "Ordering Information", "Part Numbering",
    "Device Nomenclature", "Part Number Construction",
    "Marking and Pin Configuration",
    "Ordering Code" tables                      -> all manufacturers
  * For eMMC/UFS: "Product Family", "Product Lineup",
    "Ordering Information" or marking tables on cover page

================================================================
 SPECIAL HINTS PER COMPONENT FAMILY
================================================================

eMMC / UFS (managed NAND with controller)
-----------------------------------------
  * Density code is usually a one- or two-character group near the
    end of the part number. Typical mappings (Samsung scheme,
    others are similar):
        4G  = 4   GB
        8G  = 8   GB
        AG  = 16  GB
        BG  = 32  GB
        CG  = 64  GB
        DG  = 128 GB
        EG  = 256 GB
        FG  = 512 GB
  * Capacity is given in BYTES (GB), NOT in bits.
  * Function (DMS dropdown for "Non-Volatile Memory Serial") = "eMMC"
    -> UFS variants are also mapped to "eMMC" because that's the
       closest DMS dropdown value. Do NOT invent "UFS" as Function.
  * Package: typically "153-ball FBGA" (eMMC standard) or
    "153-ball BGA" (UFS 2.x). NumberOfPin = 153 in that case.
  * Interface_internal = "NAND Flash"
    Interface_external = "eMMC 5.1" / "UFS 2.1" / "UFS 3.0" / "JEDEC eMMC"

SERIAL FLASH (SPI / QSPI / OctalSPI)
------------------------------------
  * Density code is typically a numeric block ("64", "128", "256", "512")
    -> ALWAYS in MEGABIT (Mb / Mbit), never bytes.
        "64"  = 64 Mbit  =  8 MB
        "128" = 128 Mbit = 16 MB
        "256" = 256 Mbit = 32 MB
        "512" = 512 Mbit = 64 MB
  * Function (DMS dropdown for "Non-Volatile Memory Serial") = "Flash"
    -> "Serial NOR Flash", "QSPI", "SPI NAND" all map to "Flash".
  * Package: SOIC-8 / SOIC-16 / WSON-8 / VSOP-8 / BGA-24 / KGD.
  * Width  : 1 (Std SPI), 2 (Dual), 4 (Quad), 8 (Octal) - take the MAX
             advertised, e.g. QSPI -> Width = "4 bit".

SERIAL EEPROM
-------------
  * Density code: "01" / "02" / "04" / "08" / "16" / "32" / "64" / "128"
    -> all in KILOBIT, except 256 / 512 / M02 / M04 in Microchip's
       Mbit naming (M02 = 2 Mbit, M04 = 4 Mbit, ...).
  * Function = "EEPROM".
  * Width = "1 bit" for SPI EEPROM, "1 bit" for I2C EEPROM
    (data line is single).

SERIAL F-RAM / MRAM
-------------------
  * Function = "FRAM" / "MRAM" (NEVER "Flash").
  * Density: usually given in bits (Kb / Mb).

PARALLEL NOR / NAND
-------------------
  * For "Non-Volatile Memory Parallel" the DMS Function dropdown
    accepts: "NOR Flash", "NAND Flash SLC", "NAND Flash MLC",
             "EEPROM", "MRAM", "FRAM".
  * Decision tree:
       NAND + MLC/Multi-Level   -> "NAND Flash MLC"
       NAND (no MLC mention)    -> "NAND Flash SLC"
       NOR / Parallel NOR       -> "NOR Flash"
       Magnetoresistive / MRAM  -> "MRAM"
       Ferroelectric / FRAM     -> "FRAM"
       EEPROM (no Flash kw)     -> "EEPROM"

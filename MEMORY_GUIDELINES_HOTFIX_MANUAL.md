## ?? Anleitung

1. Öffne: `DatasheetAnalyzer.Core/Services/DMSCatalogService.cs`
2. Suche nach: `private string GetEmbeddedMemoryGuidelines()`
3. Ersetze die GESAMTE Methode mit der folgenden Version:

```csharp
        /// <summary>
        /// Embedded Memory-Guidelines (UPDATED: Size in Bytes, Function Dropdown)
        /// </summary>
        private string GetEmbeddedMemoryGuidelines()
        {
            return @"
?????????????????????????????????????????????????????????
```

## ?? Alternative: PowerShell Script

Wenn manuelle Bearbeitung zu fehleranfällig ist:

```powershell
# memory_guidelines_hotfix.ps1
$file = "DatasheetAnalyzer.Core\Services\DMSCatalogService.cs"
$content = Get-Content $file -Raw

# Backup erstellen
Copy-Item $file "$file.backup"

# Suche nach GetEmbeddedMemoryGuidelines() und ersetze
$pattern = '(?s)(private string GetEmbeddedMemoryGuidelines\(\).*?return @")(.*?)(";\s*})'

$replacement = '$1
???????????????????????????????????????????????????????????????????
 MEMORY EXTRACTION GUIDELINES (UPDATED)
???????????????????????????????????????????????????????????????????

?? CRITICAL: SIZE MUST BE IN BYTES, FUNCTION MUST BE EXACT VALUE!

1?? SizeByte = INTEGER IN BYTES
   256 Kbit ? 32768
   32 Mbit ? 4194304

2?? Function = EXACT DROPDOWN
   FRAM (NOT ""Memory""!)
   EEPROM
   NOR Flash
$3'

$content -replace $pattern, $replacement | Set-Content $file

Write-Host "? GetEmbeddedMemoryGuidelines() updated!"
```

## ? **FALLS HEADER IMMER NOCH FEHLT:**

### **Problem-Check 1: Shape-Dateien laden**
Öffnen Sie **Browser Entwicklertools** (F12) ? **Network Tab**:

**Suchen Sie nach:**
- `shape.css` ? sollte Status **200 OK** haben
- `shape.js` ? sollte Status **200 OK** haben
- `theme.css` ? sollte Status **200 OK** haben

**Falls 404 Fehler:**
```sh
# NuGet-Pakete neu wiederherstellen
dotnet restore

# App neu builden
dotnet build

# App neu starten
dotnet run
```

### **Problem-Check 2: JavaScript-Fehler**
Öffnen Sie **Browser Entwicklertools** (F12) ? **Console Tab**:

**Prüfen Sie auf Fehler wie:**
- `ReferenceError: ... is not defined`
- `Failed to load resource: shape.js`

**Lösung:**
```sh
# Browser-Cache komplett leeren
# Chrome: Entwicklertools ? Application ? Clear Storage ? Clear site data

# App neu starten
dotnet run
```

### **Problem-Check 3: CSS wird nicht geladen**
**Prüfen Sie** `DatasheetAnalyzer.Blazor\bin\Debug\net8.0\wwwroot\_content\`:

**Sollte enthalten:**
- `RohdeSchwarz.SHAPE.BlazorComponents/`
  - `css/shape.css`
  - `js/shape.js`
- `RohdeSchwarz.SHAPE.WebApplication.Theme/`
  - `css/theme.css`

**Falls fehlend:**
```sh
# Clean + Rebuild
dotnet clean
dotnet build
dotnet run
```

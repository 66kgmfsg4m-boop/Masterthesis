 SPECIAL INSTRUCTIONS FOR NON-VOLATILE MEMORY EXTRACTION
???????????????????????????????????????????????????????????????????????

?? CRITICAL: COMPONENT TYPE SPECIFICATION
   Your datasheet belongs to a SPECIFIC memory subcategory:
   - "Non-Volatile Memory Serial" (SPI/I2C memories like AT25xxx)
   - "Non-Volatile Memory Parallel" (Parallel memories like AT28xxx)
   
   DO NOT use generic "Memory Components" - use the EXACT subcategory!

? CRITICAL DIFFERENCE: Serial vs. Parallel Memory ICs
   Serial:   SPI/I2C interface, fewer pins (6-8), slower access (µs)
   Parallel: Address/Data bus, many pins (20-48), faster access (ns)

?? SIZE = MEMORY CAPACITY (NOT PHYSICAL DIMENSION!)
   In Memory Components, "Size" property means MEMORY SIZE in Bits/Bytes!
   ? Size = "1 Mbit" (from title "1-Mbit EEPROM")
   ? Size = "3.9 mm" (that's package width - WRONG!)
   
   WHERE TO FIND:
   ? First page title: "1-Mbit Serial EEPROM"
   ? Features: "256 Kbit of EEPROM"
   ? Organization: "128K x 8"
   ? DO NOT look in "Package Dimensions" section!

???????????????????????????????????????????????????????????????????????
?? WHERE TO FIND MEMORY PARAMETERS
???????????????????????????????????????????????????????????????????????

1. TIMING PARAMETERS (tAA, tRC, tWC):
   • Section: "AC Characteristics" or "Timing Specifications"
   • Table format: Symbol | Min | Typ | Max | Unit | Description
   • Located after "DC Characteristics"

2. CAPACITY AND ORGANIZATION:
   • First page in "Features" or "Product Description"
   • Format: "64 Kbit", "128K x 8", "1 Mbit"
   • Organization: Address depth × Data width (e.g., "8K x 8" = 8 KB)

3. INTERFACE TYPE:
   • Serial: "SPI", "I2C", "Microwire" mentioned in Features
   • Parallel: "Parallel Interface" or pin names (A0-A15, D0-D7)

4. VOLTAGE AND POWER:
   • Section: "DC Characteristics" or "Electrical Specifications"
   • Supply Voltage (VCC), Current (ICC)

5. PACKAGE DIMENSIONS (Pitch):
   • Same as RF Amplifier: "Package Information and Dimensions"
   • Dimension 'e' in mechanical drawings

???????????????????????????????????????????????????????????????????????
? TIMING PARAMETER EXTRACTION (tAA, tRC, etc.)
???????????????????????????????????????????????????????????????????????

CRITICAL: Property name suffix determines which column to read!

???????????????????????????????????????????????????????????????????????
? Property Name    ? Read from Column   ? Example                     ?
???????????????????????????????????????????????????????????????????????
? tAA_Max          ? MAX column ONLY    ? tAA ? Max = 55 ns           ?
? tRC_Min          ? MIN column ONLY    ? tRC ? Min = 55 ns           ?
? tWC_Typ          ? TYP column ONLY    ? tWC ? Typ = 10 µs           ?
? tAA (no suffix)  ? TYP (default)      ? tAA ? Typ (or Max if no Typ)?
???????????????????????????????????????????????????????????????????????

TIMING PARAMETER DEFINITIONS:

• tAA = Address Access Time
  ? Time from address valid to data output valid
  ? ONLY relevant for PARALLEL memory (NOT serial!)
  ? Typical values: 45ns - 120ns
  ? Unit: ns (nanoseconds)

• tRC = Read Cycle Time
  ? Minimum time between consecutive read operations
  ? Typical values: 55ns - 150ns
  ? Unit: ns

• tWC = Write Cycle Time
  ? Minimum time between consecutive write operations
  ? Typical values: 5µs - 10ms (much slower than read!)
  ? Unit: µs or ms

• tOE = Output Enable Time
  ? Time from OE# active to data output valid
  ? Typical values: 20ns - 50ns

? IMPORTANT: 
   - For SERIAL memory: tAA is NOT relevant (return "nicht relevant" or "nicht vorhanden")
   - For PARALLEL memory: tAA is critical performance metric
   - Always include unit (ns, µs, ms)
   - Keep exact value from datasheet (don't round!)

???????????????????????????????????????????????????????????????????????
?? CAPACITY AND ORGANIZATION EXTRACTION
???????????????????????????????????????????????????????????????????????

CAPACITY FORMATS:
• "64 Kbit" = 64 Kilobit = 8 KB
• "1 Mbit" = 1 Megabit = 128 KB
• "128 KB" = 128 Kilobyte = 1 Mbit

ORGANIZATION FORMATS:
• "8K x 8" = 8192 addresses × 8 bits data width
• "16K x 16" = 16384 addresses × 16 bits data width
• "128K x 8" = 131072 addresses × 8 bits = 128 KB = 1 Mbit

EXTRACTION RULES:
1. Extract EXACTLY as written in datasheet (keep original format!)
2. If both Capacity and Organization present:
   ? Extract both separately
   ? Example: Capacity="1 Mbit", Organization="128K x 8"
3. DO NOT calculate/convert (keep original notation)
4. If missing: "nicht vorhanden"

?? INTERFACE TYPE EXTRACTION
???????????????????????????????????????????????????????????????????????

SERIAL MEMORY INDICATORS:
• Pin names: MISO, MOSI, SCK, CS#, SDA, SCL
• Features mention: "SPI Interface", "I2C", "Microwire", "3-wire"
• Pin count: 6-8 pins (typical for serial)
• Examples: "SPI", "I2C", "Microwire"

PARALLEL MEMORY INDICATORS:
• Pin names: A0-A15 (address bus), D0-D7 (data bus)
• Features mention: "Parallel Interface", "Asynchronous"
• Pin count: 20-48 pins (typical for parallel)
• Examples: "Parallel", "Asynchronous Parallel"

EXTRACTION:
? Extract EXACTLY as described in datasheet
? Examples: "SPI", "I2C", "Parallel", "Asynchronous"

???????????????????????????????????????????????????????????????????????
?? WIDTH (DATA BUS WIDTH) - SPECIAL HANDLING
???????????????????????????????????????????????????????????????????????

? CRITICAL: "Width" refers to DATA BUS WIDTH (not physical dimension!)

PROPERTY NAMING:
• Width_Max = MAXIMUM data bus width (read from MAX column if table)
• Width_Typ = TYPICAL data bus width
• Width (no suffix) = Use TYP or stated value

COMMON VALUES:
• Serial Memory: Width = "1 bit" (serial data line)
• Parallel Memory (x8): Width = "8 bit"
• Parallel Memory (x16): Width = "16 bit"

EXTRACTION RULES:
1. Look in "Organization" or "Memory Array" section
2. From "8K x 8" ? Width = "8 bit"
3. From "128K x 16" ? Width = "16 bit"
4. If property name contains "Max": Read from MAX column
5. Always include unit "bit" (not bytes!)

EXAMPLES:
? CORRECT: Width = "8 bit"
? CORRECT: Width_Max = "16 bit"
? WRONG: Width = "8" (missing unit!)
? WRONG: Width = "1 byte" (should be "8 bit")
? WRONG: Width = "3.9 mm" (that's physical dimension, not data width!)

?? SERIAL VS. PARALLEL DIFFERENCES
???????????????????????????????????????????????????????????????????????

????????????????????????????????????????????????????????????????????
? Parameter            ? Serial Memory       ? Parallel Memory     ?
????????????????????????????????????????????????????????????????????
? tAA (Address Access) ? "nicht relevant"    ? Extract from MAX    ?
? Interface            ? "SPI", "I2C"        ? "Parallel"          ?
? Width (Data Bus)     ? "1 bit"             ? "8 bit", "16 bit"   ?
? Pin Count            ? 6-8 pins            ? 20-48 pins          ?
? Typical Package      ? SOIC-8, DFN-8       ? DIP-28, TSOP-32     ?
? Access Time Range    ? µs (microseconds)   ? ns (nanoseconds)    ?
????????????????????????????????????????????????????????????????????

DECISION LOGIC:
IF Interface contains "SPI" OR "I2C" OR "Serial":
   ? Serial Memory
   ? tAA = "nicht relevant"
   ? Width typically "1 bit"

IF Interface contains "Parallel" OR Pin count > 16:
   ? Parallel Memory
   ? tAA = Extract from AC Characteristics (MAX column)
   ? Width = Extract from Organization (8 or 16 bit typical)

? QUICK EXTRACTION CHECKLIST FOR MEMORY
???????????????????????????????????????????????????????????????????????

STEP 1: Determine Memory Type
? Check Features section for "SPI", "I2C" ? Serial
? Check pin names (A0-A15, D0-D7) ? Parallel
? Count pins: <16 ? Serial, >16 ? Parallel

STEP 2: Extract Timing Parameters
? Find "AC Characteristics" table
? For tAA_Max: Read MAX column (ONLY for Parallel!)
? For tRC_Min: Read MIN column
? Include unit (ns, µs)

STEP 3: Extract Capacity/Organization
? Look at first page (Features section)
? Extract exactly as written (e.g., "1 Mbit", "128K x 8")
? Do NOT convert or calculate!

STEP 4: Extract Data Bus Width
? From Organization: "8K x 8" ? Width = "8 bit"
? If property is "Width_Max": Read from MAX column
? Always include unit "bit"

STEP 5: Extract Interface
? Serial: "SPI", "I2C", "Microwire"
? Parallel: "Parallel", "Asynchronous"

STEP 6: Extract Pitch (Package Dimensions)
? Find mechanical drawing section
? Look for dimension 'e' (pin spacing)
? Typical: 0.5mm (TSOP), 1.27mm (SOIC), 2.54mm (DIP)

? COMMON MISTAKES TO AVOID
???????????????????????????????????????????????????????????????????????

MISTAKE 1: Extracting tAA for Serial Memory
? WRONG: "tAA": "150 ns" (for SPI memory)
? CORRECT: "tAA": "nicht relevant" (Serial has no address access time!)

MISTAKE 2: Confusing Width with physical dimensions
? WRONG: "Width": "3.9 mm" (that's package width!)
? CORRECT: "Width": "8 bit" (data bus width from organization)

MISTAKE 3: Converting units without request
? WRONG: "Capacity": "131072 bytes" (converted from 128K x 8)
? CORRECT: "Capacity": "1 Mbit" (as written in datasheet)

MISTAKE 4: Using MIN column for tAA_Max
? WRONG: tAA_Max reads from MIN column
? CORRECT: tAA_Max reads from MAX column (suffix determines column!)

MISTAKE 5: Guessing Interface type
? WRONG: Assuming "SPI" when unclear
? CORRECT: Return "nicht klar erkennbar" if ambiguous

?? VALIDATION RULES FOR MEMORY PARAMETERS
???????????????????????????????????????????????????????????????????????

TIMING PARAMETERS:
1. tAA (Address Access Time):
   ? Range: 10 ns - 200 ns (for parallel memory)
   ? Outside range: Likely wrong column or unit
   ? For Serial: Must be "nicht relevant"!

2. tRC/tWC (Cycle Times):
   ? Range: 20 ns - 1 ms
   ? tWC is typically MUCH longer than tRC (write slower than read)

3. Unit MUST be included:
   ? "55 ns", "10 µs", "5 ms"
   ? "55" (missing unit!)

CAPACITY:
1. Valid formats:
   ? "64 Kbit", "1 Mbit", "128 KB"
   ? "64000 bit" (too precise, use standard notation)
   ? "8 KB" when datasheet says "64 Kbit" (keep original!)

2. Typical values:
   ? 64 Kbit, 128 Kbit, 256 Kbit, 512 Kbit
   ? 1 Mbit, 2 Mbit, 4 Mbit, 8 Mbit, 16 Mbit
   ? 73 Kbit (unlikely, probably wrong!)

ORGANIZATION:
1. Format: "Address × Width"
   ? "8K x 8", "32K x 8", "64K x 16"
   ? "8Kx8" (missing spaces)
   ? "8192 × 8" (use K notation from datasheet)

WIDTH (Data Bus):
1. Valid values:
   ? Serial: "1 bit"
   ? Parallel: "8 bit", "16 bit", "32 bit"
   ? "1 byte" (should be "8 bit")
   ? "3.9 mm" (that's physical dimension!)

2. If ambiguous:
   ? Extract from Organization (8K x 8 ? "8 bit")

INTERFACE:
1. Valid values:
   ? "SPI", "I2C", "Microwire", "Parallel", "Asynchronous"
   ? "Serial" (too generic, specify SPI/I2C)
   ? "Fast" (not a type, that's a speed descriptor)

PITCH:
1. Follow same rules as RF Amplifier
2. Typical Memory values:
   ? 1.27mm (SOIC-8 serial)
   ? 2.54mm (DIP parallel)
   ? 0.5mm (TSOP parallel)

?? SPECIAL CASES
???????????????????????????????????????????????????????????????????????

CASE 1: Multiple Access Times (tAA, tACC, tCE)
? If property is "tAA" but datasheet uses "tACC":
  Extract tACC value as tAA (they mean the same)
? If multiple access times exist, use the longest (worst-case)

CASE 2: Organization with multiple configurations
Example: "64K x 8 or 32K x 16"
? Extract FIRST configuration: "64K x 8"
? Width depends on configuration: "8 bit" (from first config)

CASE 3: Voltage-dependent timing
Example: tAA = 45ns @ 5V, 55ns @ 3.3V
? Extract the SLOWER value (worst-case): "55 ns"
? Or extract for specified voltage (check property name)

CASE 4: Temperature-dependent timing
Example: tAA = 45ns @ 25°C, 55ns @ 70°C
? Extract MAX value: "55 ns"

?? CONFIDENCE SCORING FOR MEMORY PARAMETERS
???????????????????????????????????????????????????????????????????????

HIGH CONFIDENCE (0.9-1.0):
• All parameters found in clearly labeled sections
• AC Characteristics table with Symbol column
• Capacity and Organization in Features section
• Package drawing with dimension 'e' for Pitch

MEDIUM CONFIDENCE (0.7-0.9):
• Parameters found but not all clearly labeled
• Timing from text (not table)
• Organization calculated from capacity
• Pitch inferred from package type

LOW CONFIDENCE (0.5-0.7):
• Missing AC Characteristics section
• Capacity mentioned but not Organization
• No mechanical drawing for Pitch

NO CONFIDENCE (<0.5):
• No timing information (return "nicht vorhanden")
• No capacity information
? Return "nicht gefunden" for missing values
